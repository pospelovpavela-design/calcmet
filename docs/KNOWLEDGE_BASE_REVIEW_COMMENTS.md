## Comment 3

Автор: Алексеев Евгений Сергеевич

Дата: 2026-03-18T18:47:00Z

Фрагмент: `` `a_пр` — шаг прогонов (принимается = шагу ферм B). ``

Комментарий:

> Шаг прогонов задается пользователем, он не равен шагу ферм. При этом калькулятор, судя по полученным значения считает по умолчанию шаг прогонов равный 3 метров. Судя по полученным данным количество прогонов на фермах по одному ряду программа определяет по следующей формуле: B (пролет)/а (шаг прогонов по умолчанию 3м). К этой формуле надо автоматом плюсовать еще три прогона: в коньке ферм их ставится 2, по краям крыши так же по 2. Так что конечная формула должна выглядеть так (B/a + 3)*L (длина пролета)* m (масса погонного метра прогона)
